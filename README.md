# TikTok Batch Downloader (Terminal) V2

tiktok video downloader, download 1 or many videos at once by pasting the link or importing from urls.txt

## Installation

```bash
git clone https://github.com/hiiell/Tiktok-batchDownloaderV2.git
cd Tiktok-batchDownloaderV2
pip install -r requirements.txt
```
